# Modalità Adulto · immagini dei post

Immagini pubbliche di post e storie di [@modalita.adulto](https://www.instagram.com/modalita.adulto/).
Servono all'API di Instagram, che scarica le immagini da un indirizzo pubblico. Le carica in automatico
`publish/instagram.py` del repository di lavoro; qui non va modificato niente a mano.
